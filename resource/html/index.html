How to use

Choose a pack, pick a component or prop, preview drawables and textures, then capture manually or run Auto Preview.

Put clothing packs in resources/[clothingpacks]/pack_name/stream and restart the studio to detect them.

Commands: /tpmstudio, /tpmscreenshot, /tpmautopreview, /tpmpausepreview, /tpmresumepreview, /tpmstoppreview.

All registered keybinds can be changed in FiveM/GTA key bindings after the resource restarts.
