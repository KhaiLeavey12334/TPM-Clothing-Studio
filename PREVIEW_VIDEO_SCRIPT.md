# TPM Clothing Studio Preview Video Script

This is a simple structure for recording a clean Discord, YouTube, or Tebex preview video. You can record it with or without voice.

## Video Goal

Show that TPM Clothing Studio saves creators time by previewing clothing directly inside FiveM, cycling drawables and textures automatically, and producing catalogue-ready screenshots without opening Blender for every item.

## Short Product Line

No more wasting hours setting up clothing previews in Blender. TPM Clothing Studio lets you preview, frame, and screenshot your FiveM clothing packs directly in-game.

## 60-90 Second Video Structure

### 1. Opening Shot

What to show:
- Spawned in-game.
- Press `F1`.
- Let the TPM Clothing Studio UI open.

Optional voice:
> This is TPM Clothing Studio, a FiveM clothing preview and screenshot tool built to speed up clothing pack previews and catalogue work.

### 2. Show The Browser

What to show:
- Click through Browser.
- Switch component slot.
- Change drawable.
- Change texture.

Optional voice:
> Instead of loading every item into Blender just to check how it looks, you can preview drawables and textures live in FiveM, exactly where players will see them.

### 3. Show Camera Options

What to show:
- Open Screenshot tab.
- Select Full Body, Torso, Head, or Shoes.
- Select Front or Back.
- Move back to the preview.

Optional voice:
> The screenshot camera can be locked to full body, torso, head, or shoes, with front and back angles for consistent product shots.

### 4. Manual Screenshot

What to show:
- Click Take Screenshot or press the screenshot key.
- Show the menu hiding.
- Show success notification.
- Briefly show the screenshots folder.

Optional voice:
> Manual screenshots hide the UI, capture the item, then reopen the studio with the save location shown.

### 5. Auto Screenshot

What to show:
- Go to Studio.
- Click Start.
- Enter a start drawable.
- Enter an end drawable.
- Let it cycle a few items and textures.
- Show the progress bar.

Optional voice:
> Auto mode can capture a whole drawable range and every texture inside that range, saving hours of repetitive clicking.

### 6. Pack Name And Filenames

What to show:
- Open Settings.
- Add a pack name.
- Show an example screenshot filename.

Optional voice:
> You can add a pack name prefix so screenshots are saved with clean, organised filenames for catalogues, Discord posts, or store listings.

### 7. Ped Chooser

What to show:
- Select Male.
- Select Female.
- Apply a detected ped if available.

Optional voice:
> The ped chooser supports male, female, and configured ped folders, so you can preview clothing on the body you actually need.

### 8. Closing Shot

What to show:
- A folder with multiple generated screenshots.
- A few clean clothing preview images.

Optional voice:
> TPM Clothing Studio keeps your preview workflow inside FiveM, cuts down setup time, and helps you produce catalogue-ready clothing screenshots much faster.

## No-Voice Version

Use these text captions:

1. TPM Clothing Studio
2. Preview FiveM clothing directly in-game
3. Browse drawables and textures live
4. Lock camera presets for clean screenshots
5. Capture manual screenshots instantly
6. Auto-capture drawable ranges and every texture
7. Save hours of repetitive preview work
8. Built for clothing creators, server owners, and catalogue teams

## Recording Tips

- Record in daylight with clear weather.
- Use the same camera preset for the whole demo.
- Keep the video short and fast.
- Show the screenshots folder near the end so people trust the output.
- Avoid too much talking over menus; let the UI prove the feature.
- If posting in Discord, make a shorter 30-second cut with captions only.
